# Trexpenser — Landing Page

The marketing and customer-facing website for Trexpenser. Built for performance, SEO, and smooth animations.

🔗 **Live:** [trexpenser.vercel.app](https://trexpenser.vercel.app)

---

## Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Animations:** Motion v12 (Framer Motion)
- **React:** v19

## Purpose

This is the public-facing site — it covers the product intro, features, pricing, and directs users to sign up or log in to the app.

## Getting Started

```bash
git clone https://github.com/Abosi-Godwin/trexpenser.git
cd trexpenser
npm install
npm run dev
```
